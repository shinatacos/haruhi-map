# 聖地巡礼マップエディター — 2026年11月 関西

**ハルヒ＋ゆずソフト作品＋鉄道＋SOS展を、地図と1分単位の旅程で直接編集するWebアプリ**。GitHubやサーバーへの登録は不要です。

## 使い方（いちばん簡単）

1. `haruhi_map_editor_standalone.html` をダブルクリックしてブラウザで開く。
2. 左上で **「SOS展入り 改訂案」** または **「旧・分刻み旅程」** を選び、日付を選択。
3. 地図のピンまたは左側の行程をクリックして編集。位置の変更はピンの「編集する」→「地図上で位置をドラッグして修正」。新しい地点は「＋地点を追加」→地図をクリック。
4. 変更内容はこのブラウザに自動保存。**Codexで編集したい場合や別の端末に移す場合は、必ず「エクスポート → 編集用JSON」でバックアップ。**

地図の描画にはインターネット接続が必要です（LeafletライブラリとOpenStreetMapタイルを使用）。ネット接続がない場合も時刻表・地点一覧の一部の編集は動作します。

## Codexで編集する（Windows / PowerShell）

1. ZIPを展開し、**展開したフォルダ全体**をCodexの作業フォルダとして開く。
2. `CODEX_TASK.md` をCodexに読ませる（最初に `AGENTS.md` も読ませる）。
3. 例：`「AGENTS.md と CODEX_TASK.md に従い、11/20の巡礼順を徒歩経路を優先して並べ直して。元の計画も残して」`
4. 変更後、PowerShellで以下を実行。

```powershell
python tools\check_data.py
python tools\build_seed.py
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開く。終了は PowerShell 側で `Ctrl+C`。

Pythonがなくても `haruhi_map_editor_standalone.html` は単体で開けます（ネット接続必要）。

**注意：** Codexがソースを更新しても、ブラウザで先に編集していたデータは自動反映されません。既存の変更を失いたくないときは、JSONで書き出し、Codexに渡してマージしてもらってください。更新ソースを使うときは、バックアップ後に「初期データに戻す」で読み直してください。

## ファイル

- `index.html` ... 開発用アプリの画面
- `styles.css` ... レイアウトとデザイン
- `app.js` ... 編集、検索、地図、保存、書き出し
- `data/points.json` ... 60地点の編集可能なデータ
- `data/schedule.json` ... 250件の分刻み行程
- `data/seed.js` ... 上記JSONをブラウザへ読み込む自動生成ファイル
- `tools/build_seed.py` ... データとコードから単独HTMLを再生成
- `tools/check_data.py` ... データの整合性を検査
- `haruhi_map_editor_standalone.html` ... ダブルクリックで開ける単一HTML
- `AGENTS.md` ... Codex向けの指示・安全基準
- `CODEX_TASK.md` ... Codexに貼り付ける初回指示

## できること

- ピン60地点の追加・削除・編集・ドラッグ移動
- 旧旅程193件 / SOS展改訂旅程57件を日付ごとに表示
- 行動の時間、日付、作品関連地点、メモ、訪問状況を編集
- ピンからGoogleマップ検索を開く
- 編集をブラウザ内に保存し、編集用JSONでバックアップ・読み込み
- My Maps向けCSV / KML、GIS向けGeoJSON、時刻表CSV出力

## 正確性について

元の60地点のうち**14地点は公表資料などで座標確認され、残る46地点は周辺を示す概略ピン**です。「ハルヒ坂」の細かな撮影角度・住宅地・踏切位置を保証するナビではありません。鉄道や徒歩の移動時間もユーザー用の計画値を含み、すべて実際のダイヤで検証したものではありません。地図の点線は**地点と地点を直線で結んだ参考線**で、徒歩道・線路・道路には沿いません。

当日、学校や施設の公開・撮影条件に従ってください。OSM地図の著作権表示を保持しています。

## 改善版の補足

JSON読み込みは重複ID・座標・時刻・参照先を検査します。読み込み／初期化の直前データはブラウザに1世代保存し、エクスポートの「置換前バックアップJSON」から取り出せます。通常の編集用JSONバックアップも続けてください。時刻の出典を編集・CSV出力できます。公道との座標照合や公式ダイヤ照合は今回実施していません。汎用化は REUSABLE_DEVELOPMENT.md に別開発案として保存しています。
